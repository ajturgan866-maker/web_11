# Видеособеседование 1 на 1 (WebRTC)

Простое веб-приложение для видеозвонков 1 на 1 на базе WebRTC и WebSocket signaling-сервера `wss://inai-col3.fishrungames.com/signaling/`.

## GitHub Pages

Сайт: https://ajturgan866-maker.github.io/web_11/

При отправке изменений в ветку `main` GitHub Actions автоматически собирает и публикует приложение.

## Запуск

```bash
cd band-hw11-website
npm install
npm run dev
```

Проверка сборки и линтера:

```bash
npm run build
npm run lint
```
